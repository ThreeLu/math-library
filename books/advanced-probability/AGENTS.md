# 高等概率论之课堂笔记 · 协作约定

本文件写给在这个目录里工作的 AI 助手（Claude Code、ChatGPT／Codex 等）。作者会让不同的 AI 轮流工作，所以每次开工前先读完本文件和 `进度.md`，收工前更新 `进度.md` 并提交 git。

## 一、项目概况

- 书名：《高等概率论之课堂笔记》，作者王汉超，山东大学，2026–2027 学年秋季学期“高等概率论”课程。
- 教材：Durrett《Probability: Theory and Examples》第五版（`参考书籍/教材/`）。课程讲到 **Markov 链**为止，大致对应 Durrett 第 1–5 章。
- 读者：作者本人。研究生，但 **σ-代数、测度、Lebesgue 积分等测度论基础几乎等于没学过**，作者自述“基础很差，已经跟不上老师上课”。因此一切从定义讲起，证明要写得很细，写法要充分照顾基础薄弱的读者（见四之一）。
- 体例：仿照于品《数学分析之课程讲义》（原版在 `参考书籍/版式参考/`）。**只有一册**，不分册，不设单独的答案册（解答紧跟在每道题后面），不设考试、建议阅读、幻灯片、声明、卷首文章。
- 组织：按“讲”分，每讲一个相对完整的主题。**不按上课顺序、不按课次**，而按理论本身的逻辑排列；讲义要自洽、自成体系，后文只能引用前文。讲义里不写授课日期。

## 二、分工（最重要）

**讲义正文由 AI 撰写，作者审阅并提修改要求。**

1. 作者用文字告诉 AI：老师某次课讲了什么、大致怎么讲的。AI 据此到 Durrett 和其他参考资料里找到对应内容，写成讲义正文与作业。
2. AI 自行决定这部分内容放进哪一讲、放在讲内什么位置（可以新开一讲，也可以插进已有的讲）；决定之后在对话里说明。老师讲的顺序与讲义不一致是正常的。
3. 作者提出修改要求时，按要求改；没有被要求改的已写文字不要顺手重写。发现已写内容有数学错误或前后矛盾，直接指出并修正，同时在对话里说明。
4. “完成”只能由作者确认，AI 最多标到“待作者审”。
5. 调整讲次（拆分、合并、换序）时，同步更新 `讲义/高等概率论.tex` 的引入顺序、`进度.md` 与 `备课手册.md`，保证三者一致，并检查全书引用。

## 三、每次工作的流程

1. 读 `进度.md`：确认要写的讲没有别人“在做”（有的话先问作者），在“在做”一栏填上自己。
2. 在 `进度.md` 的“课堂记录”里记下作者这次描述的课堂内容（日期、要点、将放进哪一讲）。
3. 读 `备课手册.md` 对应的讲，到 Durrett 与参考讲义的指定页取材（页码一律是 PDF 页）。
4. 读 `讲义/lectures/` 中相关讲的现有内容，确保新内容与前文的记号、编号、引用衔接。
5. 写正文与作业，插入到合适位置。
6. 编译两遍，检查报错、未定义引用和超过 5pt 的溢出；需要时把 PDF 渲染成图片抽查版面。
7. 在对话里简要报告：放在哪一讲、写了哪些定义定理、作业有哪些大题、有哪些拿不准或偏离课堂的地方。
8. 收工：更新 `进度.md`（该讲状态、最后更新、清空“在做”、工作日志最上面加一条），然后 `git add -A && git commit`。

## 四、正文的写法

- **以 Durrett 为纲（作者 2026-10-15 要求，根本原则）。** 这是研究生课，讲义按 Durrett 书的思路来写：定义、定理的取法与证明路线以 Durrett 为准；Durrett 相应各节的例子（Example）尽量全部收入正文，相应各节的习题（Exercises）尽量全部收入作业并给出解答。在此基础上可以补充 Durrett 中有益于学习的其他材料和其他讲义的内容，补充的部分不能改变 Durrett 的主线。讲次的划分可以比 Durrett 的节更细（如 Durrett 1.1 拆成第 1–3 讲），但讲内顺序与 Durrett 保持一致。
- **讲清楚理论，并且有大量的例子与例题。** 正文的主体是定义、定理、证明和把它们串起来的叙述。**要有尽可能多的例子**（`example`）：典型的概率空间与分布、说明概念含义的具体情形、定理的直接应用、去掉某个条件后结论失效的反例。反例写在正文相应位置，不单独汇总。**正文中允许并鼓励写例题**（`workedexample` 环境，排作“例题.”，后接 `solution` 环境的完整解答），用来示范一个定理怎样用、一类问题怎样做；老师课堂上提的问题（如“$E\abs X<\infty$ 蕴含 $tP(\abs X>t)\to0$”）一律写成例题并给出解答。
- **要有很多于品式的解释性文字。** 除了定义、定理、证明，正文中要穿插帮助读者从大方向上理解本质的话：一个概念想描述什么直观，为什么定义成这样而不是别的样子，一个定理的条件各起什么作用，一个证明的思路是怎样的、哪一步是关键，一个例子是为了说明什么，与数学分析、线性代数中已学内容的类比，这个结果以后会用在哪里。这类文字可以写成正文段落，也可以写成带标题的 `remark`（如“注记 (为什么是可数)”）。但不写成与主线无关的长篇说理。
- **证明一律写完整、写细。** 每一步可测性的验证、每一次极限与积分（或求和）的交换、每一次用到的前文结果，都要写出来，并用 `\ref` 指明依据的定理（如“由单调收敛定理（定理~\ref{thm:integral:mct}）”）。不用“易证”“显然”“同理可得”跳过实质步骤；确实只是重复前面的论证时，说清楚是哪一步的重复、改动在哪里。ε-论证写出 ε 的具体选法。
- **测度论前置知识在正文里补全**，不假定读者学过实变函数。只有与主线关系很远又很长的证明（如 Kolmogorov 扩张定理的完整构造、Lebesgue 不可测集等），才可以放到附录或作业的法式大题里，并在正文中说明。
- **不写出处**：正文、作业里一律不标“Durrett 定理 x.y.z”一类来源，也不加 `% 来源` 注释。作者问起时在对话里回答。
- 著名定理可以在环境可选参数中标人名，如 `\begin{theorem}[Kolmogorov 0-1 律]`。**人名不加注音或生平脚注。**
- 所有概念性的名词在引入时，中文名称后用括号标注英文，如“σ-代数（σ-algebra）”“依概率收敛（convergence in probability）”。
- 中文正文用全角标点；比较符号用 `\leqslant`、`\geqslant`（模版已把 `\leq`、`\geq` 映射过去）。
- 外文材料一律译成中文。原文有错或有疏漏时照改，并在对话里说明。
- 数学要忠实：定义与定理的条件一个不丢，量词、边界、退化情形写全。

## 四之一、照顾基础薄弱的读者（2026-10-15 作者要求）

作者已经跟不上课堂，讲义的首要目标是让作者能自己读懂。每一讲按下面的顺序组织：

1. **开头用一个具体问题或例子引出本讲**（写成正文段落，不用方框导语）。
2. **`\topic{本讲用到的前文结果}`**：逐条列出本讲要用的定义与定理，每条带 `\ref` 和一句话的复述，读者忘了可以点回去。
3. **主线与选读分开**：第一遍可以跳过、跳过后不影响后文的小节或证明，标题后加 ★（`\topic{……★}`、`\begin{proof}[证明★]`），并说明跳过时需要承认什么。
4. **先具体后一般**：先在概率测度、$\R$ 上的 Lebesgue 测度、有限集合上讲清楚，再推广到一般测度空间。
5. **长证明（超过十行左右）前先写“证明思路”**（`\begin{remark}[证明思路]`），证明本身分成“第一步、第二步……”，每一步开头说明这一步要得到什么。
6. **每个定义之后紧跟例子和反例**，每个定理之后紧跟至少一个应用（例子或例题）。
7. **讲末写 `\topic{本讲小结}`**：几条要点，说明各结果之间的逻辑关系，以及哪些会在后文用到。
8. 宁可重复，不可跳步：用到前文结果时，重新写出它的内容，而不只写编号。

## 四之二、语言风格（作者要求：学习于品，不要 AI 腔）

写之前先读 `参考书籍/版式参考/于品-数学分析之课程讲义-2020.pdf` 中的相关章节（测度与积分部分在 PDF 第 433–540 页，极限部分在第 40–60 页），模仿他的语气。

- 于品的语气是课堂上老师讲话的书面化：以“我们”为主语；常用“我们先……”“为此，我们……”“按照定义”“很明显”“这因为”“换句话说”“比如说”“我们指出”“我们强调”“直观上”“如若不然”“同学们应该熟记”；解释时平实具体，常说“上述定义就是想描述下面的直观：……”“这个命题是简单的，但是其重要性不言而喻”“这是一个值得学习的证明”“问题的重要性与困难之处在于……”。
- 解释性文字要落到具体的例子或具体的数学上，例如用“抛两次硬币”说明 σ-代数是信息，用 $\mathbb Q\cap[0,1]$ 说明外测度的覆盖必须是可数的。
- 避免 AI 常见的腔调：不用“威力”“艺术在于”“惊人的”“看似矛盾”“这正是……的精髓”“关键在于”“值得注意的是”“换言之”“深刻”“优雅”“天然地”“至关重要”“不妨想象”等词；不用破折号“——”制造转折；不堆砌排比与对仗；不写空泛的总结句和“它提醒我们”一类说教；不用太多引号和强调。
- 句子朴素，宁可平铺直叙，不追求漂亮。

## 五、于品体例与作业

- 每讲一个 `\lecture{……}`，标题罗列本讲建立的知识点，可以很长；小标题用 `\topic{……}`（不编号）。**不使用 `summary` 方框导语**（作者要求），需要导入时直接写成正文段落。
- 定义、命题、引理、定理、推论**共用一个全书连续的编号**，正文为楷体；带星号的版本不编号。证明以小号楷体“证明:”起头。
- **例子（`example`）、注记、练习、问题不编号**，与于品原版一致。正文中可以偶尔放一两句 `practice` 小练习（验证定义一类），但成体系的训练放进作业。
- 引用一律用 `\label`/`\ref`，不在文字里写死编号。例子不编号，引用例子用 `\egref{标签}`（排作“第 N 页的例子”并带链接），不要写 `例子~\ref{…}`。
- **每一讲都设作业**（`\homework{作业的大结果}`，生成“N.1 作业：……”）。**每道题（包括法式大题的每一小问）后面紧跟详细解答**（`solution` 环境），作者通过读解答来学习方法。解答的要求：开头一两句说明思路；每一步写出依据（引用哪个定理，用 `\ref`）；计算不跳步；结尾在需要时指出容易出错的地方或这道题的意义。解答的详细程度不低于正文中的证明。**一道题有几个小问时，拆成子题**（在 `\item` 里再开 `questions`，排作 A1-1)、A1-2)……），每个子题后面立即跟它自己的解答，不要把几个小问的解答合在一起写（作者 2026-10-15 要求）。法式大题同样每一小问后跟解答。主文件中 `\showsolutionstrue`/`\showsolutionsfalse` 可以控制是否排出解答。三部分：
  1. `\exercisepart{基本习题}`：习题 A 为课堂内容的补充（正文中留给读者的细节、定义的验证、小性质）；习题 B、C…… 为**法式大题**（`probleme`）。
  2. `\thinkingpart`（思考题）：题目叫“问题”，字母接着往下排，难题加 `*`。
  3. `\exercisepart{课外知识：……}`：课堂之外的一个完整结果，同样用法式大题的形式。
- **法式大题是作业的核心，每讲至少一道，通常两三道。** 把一个完整的结果（经典定理、重要反例、正文某个定理的另一证明或推广）拆成递进的小问：前一问构造出的对象、证明的引理或完成的计算，要为后一问提供台阶；最后一问落在这个结果上。坡度要平缓，适合测度论基础薄弱的读者一步一步做下去；小问数量不限。
- 习题来源：Durrett 各节习题、`参考书籍/名家讲义/` 中的讲义与习题，以及其他可靠来源。选题的目的是帮助理解本讲理论，而不是凑难题。
- 全部接口见 `讲义/README.md`，示例见 `讲义/模版示例.tex`。

## 六、记号与术语约定

作者可以修改这张表；改过之后以这里为准。模版已定义的宏见 `讲义/README.md`。

- 概率空间 $(\Omega,\mathcal F,\mathbb P)$，概率测度一律写 `\P`（排作 $\mathbb P$），如 `\P(X\in B)`、`\int X\dd\P`；不是概率的 $P$（Hahn 分解的正集、Riemann 和的分割）照常写 `P`。一般测度空间 $(S,\mathcal S,\mu)$。期望一律写 `\E`（排作 $\mathbb E$），如 `\E X`、`\E\abs X`、`\E(X\mid\cG)`；作集合用的 $E$（如 $E\in\cF$、$\int_E$）照常写 `E`。方差 $\operatorname{Var}(X)$，协方差 $\operatorname{Cov}(X,Y)$，示性函数 $1_A$，条件期望 $\mathbb E(X\mid\mathcal G)$。
- 集合：$\mathbb N=\{1,2,\dots\}$（含 0 时明说），幂集 $2^\Omega$，补集 $A^c$，差集 $A\setminus B$，单调 $A_n\uparrow A$、$A_n\downarrow A$；由 $\mathcal A$ 生成的 σ-代数 $\sigma(\mathcal A)$，由随机变量生成的 $\sigma(X)$；Borel σ-代数 $\mathcal R$（$\mathbb R$ 上）与 $\mathcal R^d$，与 Durrett 一致；Lebesgue 测度 $\lambda$。
- 收敛：几乎必然 $X_n\to X$ a.s.（`\toas`），依概率 $X_n\to X$ in probability（`\toP`），$L^p$ 收敛（`\toLp`），弱收敛（依分布收敛）$X_n\Rightarrow X$、$F_n\Rightarrow F$。同分布 $X\stackrel{d}{=}Y$（`\eqd`）。独立同分布写 i.i.d.。
- 中文译名：almost surely 几乎必然；almost everywhere 几乎处处；in probability 依概率；weak convergence 弱收敛；distribution function 分布函数；random variable 随机变量；expectation／expected value 期望；measurable 可测；π-system π-类；λ-system λ-类；field／algebra 代数（域）；semialgebra 半代数；outer measure 外测度；monotone convergence theorem 单调收敛定理；dominated convergence theorem 控制收敛定理；uniformly integrable 一致可积；tail σ-field 尾 σ-代数；characteristic function 特征函数；martingale 鞅；supermartingale 上鞅；submartingale 下鞅；stopping time 停时；filtration 域流（σ-代数流）；Markov chain Markov 链；recurrent 常返；transient 暂留；stationary distribution 平稳分布。
- 积分写 $\int f\,d\mu$ 或 $\int f(x)\,\mu(dx)$，可用 `\dd`。

## 八、文件与标签命名

- 讲次会调整，所以**文件名和标签都不带讲号**。每讲一个文件 `讲义/lectures/<slug>.tex`（slug 为英文短名，如 `sigma-algebras`、`integration`），讲的顺序只由主文件里 `\input` 的顺序决定。
- 标签格式：`类型:slug:名称`，如 `def:integration:simple`、`thm:integration:mct`、`lec:integration`；作业题 `ex:integration:A3`、`ex:integration:B`。
- 文件开头写一行 `% !TEX root = ../高等概率论.tex`。

## 九、参考资料的使用

- `备课手册.md` 里的页码一律是 **PDF 页**。Durrett 第五版：PDF 页 = 原书页 + 8。
- 读 PDF：`pdftotext -layout -f 起 -l 止 文件 -`，或 PyMuPDF。公式多的页面文字层可能乱，必要时把页面渲染成图片再看。
- 联网下载请用 `curl`（本机 Python 的 `urllib` 有证书问题）。新下载的公开讲义放进 `参考书籍/名家讲义/`，并在 `备课手册.md` 与 `front/references.tex` 中登记。

## 十一、网站

本书是网站（仓库根目录的 `library.yml` 登记的一本书）的一部分。`.tex` 是唯一的源文件，网页由 `tools/build.py` 自动生成，不要手改 `site/` 下的生成文件。

- 网页上的编号全部取自 `build/高等概率论.aux`，与 PDF 一致。
- 每讲一页，作业另成一页，解答在网页上默认折叠；作业开头的说明框只在 PDF 里有。`进度.md` 表中“主题”列的第一个短语是网站侧边栏的条目名，整列是书目录页的内容说明。
- 为了让转换器正确处理，写作时额外遵守：
  - 只用 `yupin-notes.cls` 和本文件约定的环境与宏；新的记号宏加到 cls 的记号一节（注释行含“记号”之后），不要在各讲里 `\newcommand`。
  - 引用页码只用 `第~\pageref{…}~页`、`\egref`、`\wegref` 这几种写法（网页上换成链接）。
  - 不用 `\vspace`、`\hspace`、`\newpage` 等调版面的命令来表达内容。
- 本地预览网站：在仓库根目录运行 `make preview`。
- `git push` 就是发布网站。AI 只在本地提交，推送由作者决定。
