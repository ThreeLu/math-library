# 图论、概率组合与组合优化 · 写作约定

本书收作者的几门研究生课，每门课是一个分部（主文件里的 `\coursepart{...}`），讲次在每个分部内从 1 编号。目前有“图论”“组合优化”两部分，以后加“概率组合”。

## 通用

- 中文书，`\documentclass{yupin-notes}`，环境与宏见 `books/advanced-probability/讲义/README.md`。TikZ 共用样式在 `figures/preamble.tex`（顶点 `gv`、弧 `arc`、高亮 `geh`/`arch`、数组格子 `cell` 等）。
- **出自讲义的内容在开头用括号注明**，如“（讲义定理 1.4）”。图论部分的“讲义”指图论课讲义，组合优化部分指组合优化课讲义。
- **讲义有错时**：在该题（或该定理）后面的 `\begin{remark}[讲义原题有误]`（或“讲义的笔误”）里指出错误，最好给反例；写出猜测的原题，证明猜测的版本。同时在 `front/guide.tex` 的勘误表里加一行。
- 标签 `类型:文件名:名称`，如 `thm:longest-paths:long-cycle`、`we:traversal:...`、`ex:mst-prim:A2`。
- 记号宏（`\diam`、`\rad` 等）写在 `shared/latex/yupin-notes.cls` 的“记号”一节。
- `进度.md` 的“主题”一栏的第一个逗号之前是侧栏短标题。

## 图论部分：例题与方法

作者熟悉基本内容，**不写定义和简单题**，只写：讲义中没有证明或证明不完整的定理与不平凡的例题；不平凡课后题的解答；方法的归纳；每种方法 3–5 道新练习（附解答）。**按方法编排，不按讲义章节**：每讲开头说明方法，`\topic{方法：……}` 写要点，然后是例题（讲义定理用编号环境，讲义习题用 `workedexample` + `solution`）；讲后 `\homework` 是新练习。

## 组合优化部分：完整讲义

作者的目标是懂得讲义的全部内容。作者懂图论，会 Python 的基本语法（if/else），**不懂数据结构与算法**。所以：

- 图论基本概念不赘述；算法、数据结构一律从头讲。
- 每个算法按这个顺序：问题与想法 → 小例子上手算，**把每一步的数据（栈、队列、数组、堆的形状）全部列出来，不跳步** → 可运行的 Python 代码，逐段解释 → 正确性证明（写出不变量）→ 复杂度。
- 代码用 Python 3 的列表与 `collections.deque`；讲到链表时演示讲义“用数组模拟链表”的写法。顶点编号 0..n−1。
- **演示表格里的每个数都来自程序的实际输出**，并在测试里固定下来。

## 代码与测试

- 讲义里 `\begin{lstlisting}[language=Python]` 的代码块会被执行；只演示、不执行的片段写 `[language=Python,style=frag]`。
- `python3 books/graph-theory/code/run_tests.py` 按书中顺序执行全部代码块（后面的讲可以用前面讲定义的函数），再运行 `code/tests/test_<讲>.py`：与暴力枚举或 networkx 随机对拍，并核对正文中演示的每一步结果。改动代码或演示后必须重跑。
