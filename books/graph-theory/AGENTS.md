# 图论、概率组合与组合优化 · 写作约定

本书收作者三门研究生课（图论、概率组合、组合优化）中不平凡的例题、习题与方法。作者熟悉基本内容，所以这里**不写定义和简单题**，只写：

1. 讲义中没有证明或证明不完整的定理，以及不平凡的例题；
2. 讲义中不平凡的课后题（画图、写矩阵、直接套定义的题不收）的解答；
3. 每种经典方法的归纳；
4. 每种方法 3–5 道新练习，附解答。

## 体例

- 中文书，`\documentclass{yupin-notes}`，环境与宏见 `books/advanced-probability/讲义/README.md`。
- **按方法编排，不按讲义章节。** 每一讲是一种（或两三种相关的）方法：开头一段说明方法，`\topic{方法：……}` 写操作要点，然后是例题；讲后的 `\homework` 是新出的练习，每题后面紧跟 `solution`。
- **出自讲义的内容在开头用括号注明**，如“（讲义定理 1.4）”“（讲义习题 1.8）”“（讲义问答题 1.3）”。没有注明的是补充的。
- **讲义有错时**：在该题开头的 `\begin{remark}[讲义原题有误]` 里指出错误（最好给出反例），写出猜测的原题，然后证明猜测的版本。同时在 `front/guide.tex` 的勘误表里加一行。
- 讲义定理用 `theorem` 等编号环境（进入定理索引），讲义习题与例题用 `workedexample` + `solution`。
- 标签 `类型:文件名:名称`，如 `thm:longest-paths:long-cycle`、`we:longest-paths:sqrt-k`、`ex:longest-paths:A2`。
- 记号宏（`\diam`、`\rad` 等）写在 `shared/latex/yupin-notes.cls` 的“记号”一节。
