\section{Product-free sets}\label{sec:product-free}

A set $X$ in a group is \term{product-free} if there are no $x,y,z\in X$ with $xy=z$. Erd\H{o}s showed that every $n$ integers contain a sum-free subset of size $n/3$, by dilating into the middle third modulo a prime, and the same holds in abelian groups~\cite[\S1]{gow08}. Without commutativity much less is known. Babai and S\'os (1985) observed that a non-trivial coset of a subgroup of index $k$ is product-free; via the classification of finite simple groups, every group of order $n$ has a product-free set of size $cn^{4/7}$, and Kedlaya (1997) improved this to $cn^{11/14}$~\cite[\S1]{gow08}.

\begin{problem}[Babai--S\'os, 1985; see~\cite{gow08}]\label{prob:product-free}
Does every finite group $G$ have a product-free set of size $c|G|$?
\end{problem}

For example, in $\Z_7$ the set $\{3,4\}$ is sum-free, and no sum-free set has $3$ elements.
